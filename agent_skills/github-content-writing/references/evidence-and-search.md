# README 证据与补充规则

## 仓库原始证据

- 项目定位、功能、安装方式、支持平台和限制优先取自已保存的 README 或仓库官方文档。
- 每个标题都要可见地包含完整 `owner/repo`；服务端会再次校验，但写作时不得依赖该兜底。
- 不把 issue、社区转载或搜索摘要当作项目功能声明。

## 受控补充搜索

仅在 README 未说明且读者确有必要了解的背景、技术语境或部署前提上请求搜索。补充信息必须可追溯到返回证据；不能据此推断仓库已经支持某命令、平台、性能指标或商业承诺。

## 写作收束

部署步骤缺乏证据时，只说明“以项目官方文档为准”。读者应能据此判断适用场景和上线前验证项，而非获得未经核验的操作手册。
