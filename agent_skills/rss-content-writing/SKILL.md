# 官方 RSS 文案

将官方公告、版本更新或产品变更与可验证影响分开表达。写作时读取 [公告证据与补充规则](references/evidence-and-search.md)：它规定公告、兼容性资料和部署背景分别可支持的表述。

正文至少 1200 字符、4 到 8 个自然段，标题直指更新对象和变化主题。

封面与正文插图的视觉风格见 [插图风格](references/image-brief.md)：它只约束配图任务的场景与介质，写作时不必复述；图片内不得出现任何文字，由本地 OCR 质量门核验。
