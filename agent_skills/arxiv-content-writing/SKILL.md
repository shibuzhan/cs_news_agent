# arXiv 论文文案

面向普通科技读者解释研究问题、方法与可验证的贡献。写作时读取 [论文证据与补充规则](references/evidence-and-search.md)：它定义论文原始事实、实验结论与背景补充之间的边界。

正文至少 1200 字符、4 到 8 个自然段。标题应突出研究主题或论文名称，不使用夸大性的“颠覆”“全面领先”。
