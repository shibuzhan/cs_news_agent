# arXiv 论文文案

面向普通科技读者解释研究问题、方法与可验证的贡献。写作时读取 [论文证据与补充规则](references/evidence-and-search.md)：它定义论文原始事实、实验结论与背景补充之间的边界。

正文的目标字数区间以**配置页**（写作、审核与自动化）为准，4 到 8 个自然段。标题应突出研究主题或论文名称，不使用夸大性的“颠覆”“全面领先”。

分享角度：**这篇论文最反直觉或最实用的发现是什么**，为什么值得花几分钟读。用分享者口吻讲研究本身，不要写成摘要翻译，也不要用“本文提出了一种……”这类论文腔开头。

封面与正文插图的视觉风格见 [插图风格](references/image-brief.md)：它只约束配图任务的场景与介质，写作时不必复述；图片内不得出现任何文字，由本地 OCR 质量门核验。
