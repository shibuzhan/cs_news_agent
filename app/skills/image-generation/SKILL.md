# 受控草稿生图

## 参考资料

- 调用 Agnes Image 2.5 Flash 时，读取 `references/agnes-image-2.5-flash.md`；请求字段和响应解析以该文件为准。

输入只能是已保存草稿的标题、摘要和已审核正文；不读取原始网页、聊天附件或环境变量中的密钥。

- 仅当用户明确提出“生成图片、封面或插图”时调用 `ImageGenerationTool`。
- 图片必须是通用科技编辑插画：不得要求品牌标志、人物肖像、真实截图、角色原画或可识别产品外观；不得出现中文或其他任何可见文字、数字、字母、图标文字、代码、Logo、水印、标题或排版。
- 图片保存前必须通过本地 OCR 文字质量门；识别到文字即最多重试两次，仍不合格则不保存、不绑定草稿，并作为图片任务失败处理。
- 生成结果只私有保存为发布素材，并记录草稿、用途、插入段落、供应商和模型；生成不等于上传公众号。
- 自动审核流程可在缺少封面时调用一次封面生成。失败应保留审计并停止，不得改写草稿或提交发表。
- 用户勾选“自动配图”时，位置规划、后台任务、逐图生成和草稿绑定必须遵循同级 `auto-illustration` Skill；本 Skill 只约束单张图片生成与私有保存。
