# 自动配图与插图定位

只对已保存且状态为 `pending_review` 或 `needs_revision` 的草稿执行。输入只允许使用草稿标题、中文摘要和正文；不读取原始网页、聊天附件、内部提示词或环境变量密钥。

## 受控执行顺序

1. **规划位置**：调用 `IllustrationPlanner.decide(draft)`，先从正文中提取自然段，排除“原文标题：”尾注。规划器只输出结构化 `placements`，即插在第 N 段之后的位置；最多 3 张。没有合适位置时输出空数组并停止。
2. **建立后台任务**：对每个位置调用 `ContentRepository.create_image_generation_job`，再调用 `enqueue_image_generation_job`。不得在采集主任务或对话请求中同步等待图片服务。
3. **生成对应图片**：图片 Worker 仅调用 `ImageGenerationTool`，将标题、摘要、该位置相邻段落和不同的视觉方向作为受限上下文。每张图必须独立生成；同一篇文章应在构图、主体关系或场景角色上有差异，禁止复用另一位置的图片或任意网络图片。
4. **私有保存与绑定**：成功图片经格式校验后保存到私有 MinIO 素材库，并通过 `create_draft_illustration` 写入草稿、用途 `inline` 和 `placement_after_paragraph`。正文保持纯文本，不把 URL、二进制或 Markdown 图片标记写入正文。
5. **收束与状态**：所有图片任务终态后再收束。全部成功时可进入后续自动审核；任一任务失败或超时时，保留文字草稿并标记“配图未完成 / 自动审核已中断”，不得自动批准、创建公众号草稿或提交发表。

## 硬性限制

- 图片数量为 0–3 张；插入位置必须是有效正文段落后的位置。
- 图片内容只能是原创、通用科技编辑插画：不得出现品牌标志、人物肖像、真实截图、可识别产品外观、角色原画、中文或其他任何图片内文字。图片保存前必须经过本地 OCR 质量门；文字检测失败最多重试两次，仍失败时中断自动审核。
- 用户上传的图片只有在明确说“将当前图片作为封面”或“插入第 N 段后”时，才走附件绑定流程；不得被自动配图流程读取或复用。
- 只记录受控阶段、任务 ID、位置、成功/失败状态和错误摘要；不得输出模型原始思维链、原始提示词或密钥。
- 自动配图仅创建私有素材和草稿插图记录；不上传公众号、不创建草稿、不提交发表。
- 原记录重新生成且启用自动配图时，先解绑该草稿旧的系统生成图片，再为新正文生成图片；人工上传图片和私有素材对象不受影响。未启用自动配图时复用现有图片。
